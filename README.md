# Портфолио Ильдара

Личный сайт Python-разработчика: навыки, проекты с живыми ссылками на Telegram-ботов, контакты.

**Сайт:** https://ah3gon.github.io/

- [Портфолио](https://ah3gon.github.io/) — `index.html`
- [Лендинг барбершопа «Пример»](https://ah3gon.github.io/barbershop/) — `barbershop/`, демо-сайт для малого бизнеса с онлайн-записью через Telegram-бота [@zakaza1bot](https://t.me/zakaza1bot)

## Стек

Чистые HTML, CSS и JavaScript — без фреймворков и сборщиков. Хостинг — GitHub Pages.

- светлая и тёмная тема портфолио (по системе, с ручным переключателем)
- адаптив от 360 px
- коллажи проектов в webp с запасными png, открываются крупно по клику
- Open Graph-превью для ссылок в Telegram

## Запуск локально

Достаточно открыть `index.html` в браузере или поднять любой статический сервер в корне репозитория.
