# Портфолио Ильдара

Личный сайт Python-разработчика: навыки, проекты с живыми ссылками на Telegram-ботов, контакты.

- `index.html` — портфолио
- `barbershop/` — демо-лендинг барбершопа «Пример», связанный с ботом записи (в работе)

## Стек

Чистые HTML, CSS и JavaScript — без фреймворков и сборщиков. Хостинг — GitHub Pages.

- светлая и тёмная тема (по системе, с ручным переключателем)
- адаптив от 360 px
- коллажи проектов в webp с запасными png, открываются крупно по клику

## Запуск локально

Достаточно открыть `index.html` в браузере или поднять любой статический сервер в корне репозитория.
